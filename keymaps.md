# ⌨️ Keybindings Reference (keymaps.md)

Organized by plugin or feature group.

---

## 🔍 Telescope
- `<leader>ff` → Find files
- `<leader>fg` → Live grep
- `<leader>fd` → LSP diagnostics
- `<leader>fr` → Resume search
- `<leader>f.` → Recent files
- `<leader>fb` → Open buffers

---

## 🗂 NvimTree
- `<leader>e` → Toggle file explorer

---

## 🎛️ LSP
- `<leader>ch` → Hover doc
- `<leader>cd` → Go to definition
- `<leader>cD` → Go to declaration
- `<leader>ca` → Code actions
- `<leader>cr` → References
- `<leader>ci` → Implementations
- `<leader>cR` → Rename symbol
- `<leader>cf` → Format code
- `<leader>lr` → Restart all LSPs
- `<leader>jR` → Restart JDTLS

---

## 🧪 Debugging (DAP)
- `<leader>dt` → Toggle breakpoint
- `<leader>ds` → Start debugger
- `<leader>dc` → Close debugger UI

---

## 💬 Comments
- `<leader>/` → Toggle line comment (normal & visual)

---

## 🧠 Git
- `<leader>gh` → Preview hunk (Gitsigns)
- `<leader>ga` → Git add current file (Fugitive)
- `<leader>gA` → Git add all (Fugitive)
- `<leader>gc` → Git commit (Fugitive)
- `<leader>gp` → Git push (Fugitive)
- `<leader>gb` → Git blame (Fugitive/git-blame.nvim)
- `<leader>lg` → LazyGit interface

---

## 🧭 Harpoon
- `<S-m>` → Toggle mark current file
- `<Tab>` → Open Harpoon quick menu

---

## 🧘 Markdown
- `<leader>mp` → Markdown preview
- `<leader>mz` → Toggle Zen mode

---

## ☕ Spring Boot
- `<leader>Jr` → Run Spring Boot app
- `<leader>Jc` → Generate Java class
- `<leader>Ji` → Generate Java interface
- `<leader>Je` → Generate Java enum

---

## 🪟 Windows
- `<C-h/j/k/l>` → Navigate splits
- `<leader>wv` → Vertical split
- `<leader>wh` → Horizontal split

---

## 📚 Buffers
- `<leader>bn` → Next buffer
- `<leader>bp` → Previous buffer
- `<leader>bd` → Delete buffer

---

## 📏 Toggle Display
- `<leader>tw` → Toggle wrap
- `<leader>tn` → Toggle number/relativenumber
